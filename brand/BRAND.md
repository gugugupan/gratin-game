# グラタンゲーム brand

Logo direction: **C — チーズのびーる**. The long-vowel mark 「ー」 in ゲーム is a stretching, dripping cheese strand.

All files here are generated by `npm run brand` (`scripts/build-brand.mjs`). Edit the script, not the SVGs. Text is converted to outlines, so no font is needed to display them.

## Files

| File | Use |
|---|---|
| `wordmark.svg` / `wordmark@2x.png` | Primary logo on light grounds |
| `wordmark-dark.svg` / `wordmark-dark@2x.png` | On dark grounds (crust, photos) |
| `wordmark-mono.svg` | Single-color (stamps, print, embroidery) |
| `wordmark-stacked.svg` | Wordmark + `GRATIN GAME` subtitle |
| `icon.svg`, `icon-{16,32,48,192,512}.png` | App icon / avatar (rounded) |
| `icon-square.svg`, `apple-touch-icon.png` | Square icon (iOS rounds it itself) |
| `favicon.ico` | 16/32/48 multi-size favicon |
| `og-image.svg` / `og-image.png` | 1200×630 social share card |

## Colors

| Name | Hex | Role |
|---|---|---|
| Crust | `#4A2814` | Text, wordmark ink, dark ground |
| Terracotta | `#C9472D` | Dish / accent, icon ground |
| Cheese | `#F5B935` | Cheese strand, highlights |
| Cheese light | `#FFE08A` | Strand shine only |
| Cream | `#FFF1D6` | Page ground |
| Milk | `#FFF6E6` | Ink on dark grounds, cards |

## Type

- **Dela Gothic One** (OFL) — wordmark and display headings. Source TTF in `src/`.
- **Zen Maru Gothic** (OFL, Google Fonts) — UI and body text (ja / zh / en).

## Rules

- Keep the cheese strand yellow on every color version except mono.
- Minimum wordmark width: 120 px on screen. Below that, use the icon.
- Clear space around the wordmark: at least the height of 「ム」.
- Don't recolor the letters terracotta, add outlines, or set the wordmark in live text.
