# 进度记录

## 2026-10-06 ～ 10-07

**已定规则**（详见 `RULES.md`）
- 每轮点名 3 座城市。
- 两名角色，共享 4 个行动点。
- 职业 8 选 2（2026-10-07 改为从全部 8 个职业中自由选择，不再随机抽 4 个）。
- 后勤官：没有免费移动。
- 流行病学家：预判 0 点。
- 警察：驻守封城。所在城市不再被放病毒、不会爆发，外面的爆发也传不进来；拦下的每个病毒变成警察的样本。
- 变异只能给还没研制出解药的病毒株。
- 工程师、药剂师：维持现状，不调整。

**平衡**（`reports/balance.md`、`reports/police.md`）
- 当前默认规则下，启发式 AI 胜率约 54%。
- 警察约 51%；工程师最弱，约 43%；研究员、药剂师最强，约 65%。

**名字**：纸上防疫（日文 紙上防疫，英文 Paper Quarantine），2026-10-07 定下，替换暂名"疫线"。

**UI 风格**（`mockup/paper-style.html`，[Artifact](https://claude.ai/artifact/G6i9Bfpzd65eDCSF2vQyt1)）
- three.js 纸片立牌，牛皮纸地图，绿色切割垫桌面，纸胶带风格的界面。
- 镜头固定正面视角：不能旋转，也不能缩放；可以拖动平移。距离按 HUD 之间的空白区域自动计算，再拉近到约 48%。
- 镜头跟随当前行动角色：点职业卡切换，拖动后暂停跟随，双击恢复。
- 顶部只放信息：行动点、爆发、解药、上轮点名。不放标题，也不放回合数。
- 回合数做成地图上方桌面上的 3D 翻页台历，进入下一轮时翻页。
- 职业卡放在屏幕最下方，横排，照顾手机窄屏。职业卡是身份证样式："纸上防疫防疫署 · 行动人员证"，有职业色抬头、编号、蓝底证件照、能力、样本、机读码和镭射贴；当前行动的角色盖红色圆章"行动中"。
- 选人环节：点"开始游戏"后列出全部 8 张身份证（桌面 4×2，手机 2 列可滚动），选 2 张（盖"入选"章，选满后再点会抖动拒绝），点"确认出发"后开场。
- 没有底部行动栏：点角色（立牌或职业卡）后，在角色旁边竖着弹出行动菜单。菜单是深绿底板加米白按钮，和牛皮纸地图的对比更强；有小箭头指向角色，靠近右边缘时自动翻到角色左边。点数不够或条件不满足时用铅笔划掉；选中后扣行动点。
- 菜单桌面按屏幕比例切换两套摆放：横屏时道具围在地图四周；竖屏时游戏盒、便签、托盘放在上方，职业卡、铅笔、胶带放在下方。镜头按道具范围和底部按钮占用的高度自动取景。
- 菜单：高处俯视桌面，桌上有游戏盒、折叠地图、职业卡、托盘、便签、铅笔、胶带和杯渍。点"开始游戏"后约 3.6 秒：镜头推进 → 地图分两步展开 → 城市和 token 弹出 → 立牌立起 → HUD 贴上；"菜单"贴纸按原路倒放回去。
- 用户反馈：整体 UI 感觉不错。

**M1 内容**
- `web/`：Vite + TS + three.js 0.170，开发端口 5240。
- 样稿拆成模块：stage / foldMap / props / calendar / board / standee / tokens / cameraRig，以及 hud / idcard / draft。

- 修复：开局放病毒时警察封城不再产生样本。
- 开发模式按 `N` 由 AI 代打一轮。

**M2 内容**
- 行动菜单由引擎的合法行动实时生成（web/src/game/actions.ts）：
  - 同类行动按病毒株分开列出，例如"治疗 · 赤株""交接 · 金株 ×2""研制 · 苍株"。
  - 不能执行的行动写明原因：行动点不足、这里没有病毒、不在同一城市、样本不足（会显示进度）、需要在研究站等。
  - 职业专属行动：工程师的野战实验室、流行病学家的预判、卫生官的取消点名。
- 移动和快速转移进入选目标模式：地图上可去的城市出现脉动圆环，点城市执行，按 Esc 或点"取消"退出。
- 撤销：每执行一步前存一份完整快照（引擎新增 `clone(full)`，会连统计一起复制）。撤销按钮、Cmd/Ctrl+Z 都可以用。预判翻牌和结束行动时清空撤销记录。
- 预判：弹出牌库顶的 3 张城市牌，必须选 1 张移走，不能取消。
- 结束行动：还有剩余点数时弹窗确认；点数用完时按钮会脉动提示。
- 感染阶段暂时由 AI 代选变异和取消点名（M3 换成动画和玩家自己选）。
- 胜负：暂时用一个简单弹窗，可以选"再来一局"或"回到菜单"（M4 做正式结算）。
- 测试注意：浏览器面板隐藏时页面的逐帧动画会暂停，开场过渡停在一半；自动化测试时需要手动推进 `app.progress` 和刷新矩阵。

**M3 内容**
- 引擎的感染阶段改成分步推进：
  - `beginInfection()` 开始，`continueInfection()` 推进；需要玩家选择时暂停，返回 `{ kind: "mutation" | "cancel" }`。
  - 玩家选完后调用 `resolveMutation` / `resolveCancel` 再继续推进。
  - `endRound(chooser)` 保留，内部就是这个流程，模拟器照常使用。
- 事件流 `state.events`：cube / outbreak / blocked（封城拦截，是否获得样本）/ shielded（封城挡住扩散）/ guarded（急救队员守住）/ epidemic / intensify / mutation / named / cancelled / labExpired / round / lose。
- 界面按事件播放：
  - 流行病卡飞入。
  - 镜头跟到对应城市，病毒逐个落下；爆发时播放特效，爆发计数格跳动；封城和急救队员拦截时给出提示。
  - 点名时图钉移到新城市，顶部改为"本轮点名"。
  - 最后日历翻页。
- 选择界面：变异是 2 张卡 × 可选株的组合，显示徽章、效果和该株在场上的数量；卫生官取消点名是 3 张城市牌，显示现有病毒数。
- 快进：播放时点"快进"或点一下画面，速度 ×5。
- 平衡复查：28 组合 × 40 局，beam 10，胜率 49.4%，和改动前一致。

**M4 内容**
- 防疫报告：结局原因；队员；进行轮数、爆发、解药、清除病毒、移动、治疗、封城拦截的样本、流行病次数；解药研制顺序和根除轮次；本局变异。盖"防疫成功/失败"章。按钮：同队再来、换人再来、回到菜单。
- 存档：引擎新增 `serialize()` / `State.restore()`，连随机数状态一起保存，读档后结果和原局完全一致。
  - 新游戏、每一步行动、撤销、每轮结束时都写入 localStorage（`paper-quarantine:save:v1`），游戏结束时清除。
  - 菜单"继续上局"显示"第 N 轮 · 队员 A + B"。
  - 撤销记录不进存档。
- 规则手册：菜单上的"规则说明"卡和游戏中的"?"贴纸都能打开，内容包括目标、每轮流程、行动、爆发、流行病与变异、根除、8 名队员、小提示。
- 统计新增 `cures`（每株研制和根除的轮次）、`samplesCaught`。
- 手机：菜单 3 张卡自动换行；报告和规则在 390 宽度下排版正常，没有横向滚动。
